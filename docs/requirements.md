# 需求规格说明书

> 项目：公考积累宝  
> 版本：v1.0  
> 日期：2026-05-31  

---

## 一、项目概述

面向公考备考生的手机浏览器端知识积累工具。用户可随时存入成语、常识、实词、金句，通过 AI 解答公考问题并一键存入，利用间隔重复算法科学复习。

**目标用户**: 公考备考生（非技术背景）  
**使用场景**: 手机浏览器打开网址，利用碎片时间积累和复习  
**核心价值**: 一次积累、科学复习、AI 辅助

---

## 二、功能需求

### F1 — 成语积累模块
| 编号 | 功能 | 描述 |
|------|------|------|
| F1.1 | 列表展示 | 卡片式展示所有已存成语，按创建时间倒序 |
| F1.2 | 添加成语 | 表单输入：成语、释义、真题考法 |
| F1.3 | 编辑成语 | 点击成语卡片进入编辑模式，修改后保存 |
| F1.4 | 删除成语 | 点击删除按钮，弹出确认对话框后删除 |
| F1.5 | 搜索成语 | 顶部搜索框，按成语名或释义实时过滤 |

### F2 — 常识知识模块
| 编号 | 功能 | 描述 |
|------|------|------|
| F2.1 | 列表展示 | 卡片式展示，按创建时间倒序 |
| F2.2 | 添加常识 | 表单输入：标题、内容、来源（选填） |
| F2.3 | 编辑常识 | 点击进入编辑模式 |
| F2.4 | 删除常识 | 确认后删除 |
| F2.5 | 搜索常识 | 按标题或内容过滤 |

### F3 — 实词积累模块
| 编号 | 功能 | 描述 |
|------|------|------|
| F3.1 | 列表展示 | 卡片式展示，按创建时间倒序 |
| F3.2 | 添加实词 | 表单输入：实词、释义、用法/辨析 |
| F3.3 | 编辑实词 | 点击进入编辑模式 |
| F3.4 | 删除实词 | 确认后删除 |
| F3.5 | 搜索实词 | 按实词名过滤 |

### F4 — 金句积累模块
| 编号 | 功能 | 描述 |
|------|------|------|
| F4.1 | 列表展示 | 卡片式展示，按创建时间倒序 |
| F4.2 | 添加金句 | 表单输入：金句原文、出处、适用场景 |
| F4.3 | 编辑金句 | 点击进入编辑模式 |
| F4.4 | 删除金句 | 确认后删除 |
| F4.5 | 搜索金句 | 按内容过滤 |

### F5 — AI 问答模块
| 编号 | 功能 | 描述 |
|------|------|------|
| F5.1 | 聊天界面 | 对话气泡样式，用户问题靠右，AI 回答靠左 |
| F5.2 | 提问 | 输入框输入公考相关问题，发送后调用 DeepSeek API |
| F5.3 | 显示回答 | 流式或一次性显示 AI 回答（Markdown 渲染） |
| F5.4 | 存入模块 | 每条 AI 回答下方有"存入..."按钮，点击选目标模块 |
| F5.5 | 编辑后存入 | 存入前可编辑内容，确认后保存 |
| F5.6 | API Key 缺失提示 | 未配置 API Key 时提示用户去设置页配置 |

### F6 — 间隔重复复习
| 编号 | 功能 | 描述 |
|------|------|------|
| F6.1 | 今日复习提醒 | 首页显示今日需要复习的条目数量 |
| F6.2 | 复习流程 | 先展示题目→点击揭晓答案→自评打分→下一条 |
| F6.3 | 评分机制 | 4 档：忘了(1) / 模糊(2) / 记得(3) / 很熟(4) |
| F6.4 | 间隔计算 | SM-2 简化算法自动安排下次复习日期 |
| F6.5 | 跨模块复习 | 所有模块的条目混合复习 |

### F7 — 数据管理
| 编号 | 功能 | 描述 |
|------|------|------|
| F7.1 | 数据导出 | 一键导出全部数据为 JSON 文件下载 |
| F7.2 | 数据导入 | 选择 JSON 文件导入，合并到现有数据 |
| F7.3 | 清空数据 | 清空全部数据，需二次确认 |

### F8 — 人民网搜索
| 编号 | 功能 | 描述 |
|------|------|------|
| F8.1 | 跳转按钮 | 首页或积累页顶部放置按钮 |
| F8.2 | 新标签打开 | 点击跳转人民网搜索，新标签页打开 |

## 三、非功能需求

| 编号 | 类型 | 描述 |
|------|------|------|
| NF1 | 移动适配 | 最大宽度 480px，手机上可正常使用 |
| NF2 | 离线可用 | 无网络时仍可浏览和添加数据 |
| NF3 | 性能 | 1000 条数据内列表滚动流畅 |
| NF4 | 简洁 UI | 淡蓝色调，卡片式设计，操作直观 |
| NF5 | 零依赖 | 不依赖任何第三方 JS 框架或库 |
