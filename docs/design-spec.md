# UI 设计规范

> 项目：公考积累宝  
> 版本：v1.0  
> 日期：2026-05-31  

---

## 一、设计理念

- **克制**: 少即是多，信息层级清晰
- **亲和**: 淡蓝色给人平静、专注感，适合学习场景
- **高效**: 核心操作不超过 3 次点击
- **容错**: 删除操作有确认，数据可备份

---

## 二、色彩系统

### 主色板
| 色阶 | 色值 | 用途 |
|------|------|------|
| bg | `#F0F7FF` | 页面背景 |
| bg-card | `#FFFFFF` | 卡片背景 |
| primary | `#4A90D9` | 主按钮、选中态、标题 |
| primary-light | `#E8F2FC` | 浅蓝背景条、hover |
| primary-dark | `#2E6BA6` | 按钮按下态 |

### 文字色
| 色阶 | 色值 | 用途 |
|------|------|------|
| text-primary | `#2C3E50` | 正文、标题 |
| text-secondary | `#7F8C8D` | 辅助说明、时间戳 |
| text-placeholder | `#BDC3C7` | 输入框占位符 |

### 功能色
| 色阶 | 色值 | 用途 |
|------|------|------|
| success | `#27AE60` | 完成、已掌握 |
| warning | `#F39C12` | 需要注意 |
| danger | `#E74C3C` | 删除、警告 |
| border | `#E0E6ED` | 分割线、边框 |

## 三、字体排版

### 字体栈
```css
font-family: -apple-system, "PingFang SC", "Microsoft YaHei", "Helvetica Neue", sans-serif;
```
优先使用系统原生中文字体，保证渲染速度和一致性。

### 字号阶梯
| 级别 | 字号 | 行高 | 用途 |
|------|------|------|------|
| xs | 11px | 1.4 | 标签、徽章 |
| sm | 13px | 1.5 | 辅助信息、时间 |
| base | 15px | 1.6 | 正文内容 |
| md | 17px | 1.5 | 卡片标题 |
| lg | 20px | 1.4 | 页面标题 |
| xl | 24px | 1.3 | 数字统计 |

## 四、组件规范

### 卡片 (Card)
```
背景: #FFFFFF
圆角: 12px
内边距: 16px
阴影: 0 2px 8px rgba(0, 0, 0, 0.08)
卡片间距: 12px
```

### 按钮 (Button)
```
圆角: 8px
最小高度: 44px (触摸友好)
内边距: 10px 20px
字号: 15px

主按钮:
  背景: #4A90D9  文字: #FFFFFF
  按下: #2E6BA6

次要按钮:
  背景: #E8F2FC  文字: #4A90D9
  按下: #D0E4F8

危险按钮:
  背景: #FFFFFF  文字: #E74C3C  边框: #E74C3C
```

### 输入框 (Input)
```
高度: 44px
圆角: 8px
边框: 1px solid #E0E6ED
聚焦: 边框变 #4A90D9
内边距: 10px 12px
字号: 15px
```

### 底部导航栏
```
高度: 56px
背景: #FFFFFF + 顶部线 1px #E0E6ED
布局: 5 个等宽 Tab
图标在上(20px) + 文字在下(10px)
选中态: 图标/文字变 #4A90D9
未选中: 图标/文字 #BDC3C7
```

### 对话气泡（AI 问答）
```
用户气泡:
  靠右、背景 #4A90D9、文字 #FFFFFF、圆角 12px 12px 4px 12px

AI 气泡:
  靠左、背景 #E8F2FC、文字 #2C3E50、圆角 12px 12px 12px 4px
```

## 六、交互规范

### 页面过渡
- Tab 切换: 瞬间切换（无动画）
- 表单弹出: 从底部滑入
- 删除确认: 居中弹出对话框

### 反馈
- 按钮点击: 轻微缩放或颜色变化
- 数据保存: Toast 提示"保存成功"（2 秒消失）
- 数据删除: 确认对话框
- 加载中: 简单的旋转图标或"思考中..."

### 手势
- 列表上下滑动
- 点击卡片查看/编辑详情
- 长按无特殊操作（避免误触）
