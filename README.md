# 公考积累宝

手机浏览器上的公考知识积累工具，支持成语、常识、实词、金句的存入与间隔重复复习。

## 功能

- 📝 **成语积累** — 存入成语、释义、真题考法
- 📚 **常识积累** — 存入常识知识点
- 🔤 **实词积累** — 存入实词及用法辨析
- ⭐ **金句积累** — 存入金句、出处、适用场景
- 🤖 **AI 问答** — DeepSeek 驱动，回答可一键存入模块
- 📅 **间隔重复** — SM-2 算法，科学安排复习
- 📥 **导入导出** — 数据备份与恢复

## 使用方法

### 1. 打开网站
用手机浏览器打开部署后的网址。

### 2. 配置 AI（可选）
1. 去 [platform.deepseek.com](https://platform.deepseek.com) 注册
2. 在 API Keys 页面创建一个 Key
3. 在网站「我的」页面填入 Key 并保存

### 3. 开始积累
在「积累」页点击右下角 + 按钮添加内容，AI 问答页可以提问并一键存入。

## 部署方法

### 方式一：GitHub Pages（免费）
1. 注册 [GitHub](https://github.com) 账号
2. 创建新仓库，名称随意（如 `gongkao`）
3. 将本文件夹内所有文件上传到仓库
4. 进入仓库 Settings → Pages → Source 选 `main` 分支 → Save
5. 等待 1-2 分钟，获得网址 `https://你的用户名.github.io/gongkao/`

### 方式二：直接用手机打开
把 `index.html` 文件用手机浏览器打开即可使用（仅限本机）。

## 技术说明

- 纯前端，无服务器
- 数据存储在手机浏览器本地
- 不上传任何数据到第三方
- 建议定期使用「导出备份」功能

## 数据安全

所有数据仅存储在您的手机浏览器中（localStorage）。清浏览器缓存会丢失数据，请定期导出备份。
